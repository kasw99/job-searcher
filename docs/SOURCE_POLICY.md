# 채용 소스 사용 정책

이 포크는 사용 가능성이 높은 경로부터 선택합니다.

1. **공식 Open API**: 고용24처럼 문서화·승인된 API. 인증키의 승인 목적과 약관을 준수합니다.
2. **기업 자체 공개 채용 API/ATS**: 네이버·토스·쿠팡 등 채용 페이지가 공고 목록을 표시하기 위해 공개적으로 GET하는 읽기 전용 엔드포인트.
3. **공개 검색 페이지**: 잡코리아·사람인 등. 로그인·우회·지원 자동화 없이 개인 구직 목적의 저빈도 GET만 수행하며, 사이트 약관이나 robots 정책이 허용하지 않으면 사용하지 않습니다.
4. **차단된 소스**: 인증 우회, CAPTCHA 우회, 세션 탈취는 하지 않습니다. 브라우저가 필요하다는 상태만 반환합니다.

기본 통합은 1~2번만 활성화합니다. 3번 소스는 사용자가 해당 사이트의 최신 이용조건을 확인하고 명시적으로 선택할 때만 사용합니다.

## 고용24

- 공식 안내: <https://www.work24.go.kr/cm/e/a/0110/selectOpenApiIntro.do>
- 채용정보 API 명세: <https://openapi.work.go.kr/opi/opi/opia/wantedApiListVw.do>
- 인증키가 필요하며 고용24 기업회원 신청·심사를 거칩니다.
- 공식 명세에는 영리법인(개인사업자 포함)이 채용정보 API를 사용할 수 없다고 적혀 있습니다.
- `WORK24_API_KEY`는 환경 변수로만 전달하고 저장소에 커밋하지 않습니다.

플랫폼 정책은 바뀔 수 있습니다. 라이브 수집을 배포하거나 반복 실행하기 전에 각 소스의 최신 약관과 API 안내를 다시 확인하세요.
